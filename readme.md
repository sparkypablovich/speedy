# Speed Typing Test

## Описание
Это приложение замеряет вашу скорость печатания на русском языке. Вы должны на скорость написать выведенное предложение без ошибок, иначе тест будет считаться непройденным. Если Ваше предложение будет идентично заданному, то выведется время, за которое вы написали текст, и WPM (слова в минуту).

## Инструкция по запуску
Требуется: python, pyinstaller
Для установки pyinstaller введите команду: 
```pip install pyinstaller```
После напишите в терминал данную строку:
```pyinstaller --noconsole --distpath . --onefile main.py --name "speedy" --icon "icon.png"```

Далее запускаете speedy.exe
